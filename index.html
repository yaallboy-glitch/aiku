Cara Ambil API Key yang Benar

1
Buka 9Router di HP/laptop Anda
2
Di bagian API Keys, klik tombol "+ Create Key" untuk buat key baru
3
Setelah key dibuat, klik pada key tersebut untuk reveal/menampilkan nilai key asli. Nilainya biasanya seperti sk-xxxxxxxxxxxxxxxx atau string panjang lainnya
4
Copy nilai key yang ditampilkan (BUKAN nama "claude"), lalu paste di Pengaturan → API Key
5
Klik "Test Koneksi" di Pengaturan. Jika berhasil, langsung chat!
